Sales Data Analysis Using MySQL

Project Overview

This project focuses on analysing sales data using MySQL to generate meaningful business insights.

Objectives

- Analyse total sales revenue.
- Identify top-selling products.
- Find the best-performing customers.
- Analyse monthly sales trends.
- Compare category-wise performance.

Tools Used

- MySQL
- MySQL Workbench
- SQL

Database Tables

1. Customers
2. Products
3. Orders
4. Order Items

SQL Concepts

- SELECT and WHERE
- ORDER BY and DISTINCT
- Aggregate Functions
- GROUP BY and HAVING
- JOINs
- Subqueries
- CASE WHEN
- Window Functions
