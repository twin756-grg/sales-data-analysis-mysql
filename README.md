Sales Data Analysis Using MySQL

Project Overview

This project focuses on analysing sales data using MySQL to generate meaningful business insights. The main goal is to understand sales performance, customer purchasing behaviour, product performance, and revenue trends through SQL queries.

Project Objectives

- Calculate total sales revenue.
- Identify top-selling products.
- Analyse customer purchasing behaviour.
- Find monthly sales trends.
- Compare category-wise sales performance.
- Identify high-value customers.
- Analyse order and product performance.

Tools Used

- MySQL
- MySQL Workbench
- SQL

Database Tables

The project uses four relational tables:

1. Customers – Stores customer information.
2. Products – Stores product details and categories.
3. Orders – Contains order-related information.
4. Order Items – Contains product quantities and prices for each order.

SQL Concepts Used

The following SQL concepts are used in this project:

- SELECT, WHERE and ORDER BY
- Aggregate Functions (SUM, AVG, COUNT, MIN, MAX)
- GROUP BY and HAVING
- JOINS (INNER JOIN, LEFT JOIN)
- Subqueries
- CASE WHEN
- Window Functions
- Common Table Expressions (CTEs)
- Date Functions
- Conditional Aggregation

Business Questions Solved

This project focuses on answering the following business questions:

1. What is the total revenue generated from sales?
2. Which products generate the highest revenue?
3. Who are the top-spending customers?
4. What are the monthly sales trends?
5. Which product categories perform best?
6. What is the average order value?
7. Which products have the highest quantity sold?
8. How does sales performance vary across different months?
9. Which customers contribute the most to total revenue?
10. How can products be ranked based on their sales performance?

Key Business Insights

The SQL analysis helps identify:

- Overall sales revenue and business performance.
- Best-performing products based on sales.
- High-value customers and their purchasing behaviour.
- Monthly revenue patterns and sales trends.
- Category-wise sales performance.
- Product contribution to overall revenue.

Specific numerical findings can be added after analysing the actual query results.
